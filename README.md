# Visualizing surf route 
Visualizing surf route is a personal data management project built to visualizing my surf rides and email me a video and picture ready to upload on social media. I Track my surf with Apple Watch and export it aa an TCX file which i email to myself, the code process it and out comes different versions of videos and pictures which send me an email and i can upload them on social media. The project is designed as a practical learning platform for learning python, plotly, data analysis, software development and n8n for automation.
